# iPhone Safari 實機測試清單

## A. 基本
- [ ] Safari 允許麥克風。
- [ ] 加入主畫面後可啟動。
- [ ] 前景運作時不會無故停止 mic。

## B. 防重複
- [ ] 中文→英文 Speaker 播放期間不送 mic audio 給 Provider。
- [ ] Speaker 結束後 400ms 內不開新 segment。
- [ ] 播放結束後房間殘響不會觸發第二次翻譯。
- [ ] 對方真的重複相同句子時，不會因純文字相同被誤殺。

## C. 私人輸出
- [ ] AirPods 存在時繁中譯音只走私人輸出（若 Safari 能力允許）。
- [ ] AirPods 斷線時繁中譯音立即 mute。
- [ ] 不得自動 fallback 到 iPhone Speaker。

## D. 中斷
- [ ] 鎖屏 / 回前景。
- [ ] Siri / 來電 / 通知打斷後重新檢查狀態。
- [ ] Wi‑Fi / 5G 切換後能重新連線。

## E. 翻譯品質
- [ ] 數字、日期、時間。
- [ ] 姓名、飯店、機場、地名。
- [ ] 長句與停頓。
- [ ] 背景噪音。
- [ ] 對方講話時 AirPods 正在播上一句繁中。
